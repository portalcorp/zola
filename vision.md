# Portal Chat: The ultimate chat client

The goal is to build the most feature complete local chat client.

## resources:

- https://github.com/FranciscoMoretti/sparka
  - Chat Sharing - Share conversations with others and collaborate on AI-assisted projects.
  - Deep Research - Comprehensive research with real-time web search, source analysis, and cited findings.
  - Code Execution - Run Python, JavaScript, and more in secure sandboxes.
  - Document Creation - Generate and edit documents, spreadsheets, and presentations.

- https://github.com/vercel/ai-chatbot
  - AI-SDK V5
  - Context calculation
  - Support for artifacts - dynamic sheet UI

- https://github.com/ibelick/zola/tree/main
  - Nice UI from prompt-kit
  - Multi-model support: all models from models.dev supported
  - Bring your own API key (BYOK) support
  - Guest chat with rate limits
  - Still on v4

- https://github.com/zeronsh/chat
  - Resumable Streams: Continue generating responses even after a page refresh.
  - Fast Navigation: Quickly switch between different chat sessions.
